# YouTube Float v3.41

## Overview
Fixes the two pre-dashboard issues: oversized docked scaling and account label persistence.

## Changes
- Docked player watches pane width with `ResizeObserver`.
- Docked player box keeps a 16:9-derived height, capped at `72vh`.
- Webview is centered in that box instead of stretching endlessly into black/cutoff states.
- Signed-in account state/name is cached in `ctx.storage` and module memory.
- Cached account label seeds the Account button before the next login probe completes.

## Verification
- `node --check plugin.js`
- Runtime import stub confirmed docked registration and account-cache state path.
