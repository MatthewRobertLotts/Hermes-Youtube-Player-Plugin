# YouTube Float v3.34

## Overview
Fixes slow/unresponsive placement switching from v3.33.

## Root Cause
The pin button awaited `executeJavaScript(stateScript)` inside the current YouTube webview before switching. If the webview was busy, the click appeared dead.

## Fix
- Pin click is synchronous.
- Snapshot uses already-polled React progress.
- New pane starts with YouTube `t=<seconds>s` in the URL.
- Paused state still restores after load.

## Verification
- `node --check plugin.js`
- Runtime import stub confirmed one active player pane plus route/sidebar/status/palette.
- Check confirmed no `executeJavaScript` call remains inside `togglePlacement`.
