# YouTube Float v3.31

## Overview
Fixes duplicate panes when switching placement.

## Root Cause
Hermes layout keeps adopted docked pane ids in the tree. Reusing the same pane id for floating made the stale docked tile render the new floating contribution too.

## Fix
Use separate internal ids:
- `player-docked`
- `player-floating`

Only one is registered at a time.

## Verification
- `node --check plugin.js`
- Runtime import stub confirmed only one active `panes:*` contribution plus route/sidebar/status/palette.
