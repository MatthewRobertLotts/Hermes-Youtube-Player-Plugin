# YouTube Float v3.35

## Overview
Fixes docked pane chrome and adds a close/reopen lifecycle.

## Changes
- Docked player registers as a closeable `placement: main` pane docked right of workspace, forcing a visible tab/header by default.
- Adds an in-player `×` close button for pane instances.
- Closing unregisters the player pane and persists `playerOpen: false`.
- Status-bar chip and command-palette action reopen the player pane.

## Note
`/youtube` still renders the current player component as a page. A richer native dashboard should be a separate feature.
