# YouTube Float v3.29

## Overview
Adds first-class Hermes Desktop surfaces using the native `@hermes/plugin-sdk` contribution areas.

## Native Surfaces
- Docked right pane: `area: 'panes'`, docked beside `workspace`.
- Page route: `/youtube`.
- Sidebar nav: YouTube row.
- Status bar: `▶ YouTube` chip.
- Palette: `YouTube: Open player`.
- Storage: prefs use `ctx.storage` with localStorage fallback.

- Runtime import stub confirmed registered areas: panes, routes, sidebar.nav, statusBar.right, palette.
