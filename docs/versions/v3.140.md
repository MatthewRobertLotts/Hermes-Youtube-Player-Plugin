# YouTube Float v3.140

## Overview
Adds the player integration API v1: a small, stable, documented surface another Hermes Desktop
plugin can consume — player-side infrastructure only, no intelligence functionality.

## Changes
- Integration API v1 over a shared-window CustomEvent channel (request/response + pushed events).
- Read methods: getApiInfo, getCurrentVideo, getPlaybackState, getQueue, getAccountState, getChapters.
- Controls: play, pause, seekTo (clamped+validated), next, previous.
- Strict validation (rejects NaN/Infinity/negative seek, malformed envelopes, unknown methods) and
  degraded-safe defaults for a closed player / no video / absent queue / signed-in change.
- No authentication/session internals exposed; SECURITY.md trust-boundary section added.
- Contract tests freeze v1; parity tests prove the shipped bridge cannot drift or leak secrets.
- Docs: INTEGRATION_API.md + docs/api-example-consumer.md.
