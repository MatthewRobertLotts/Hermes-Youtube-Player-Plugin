# YouTube Float v3.33

## Overview
Makes pin/unpin seamless by carrying the active video across the pane remount.

## Behavior
- Before switching placement, snapshot current YouTube player state.
- Register the other pane placement.
- New pane starts the same video and seeks to the old timestamp.
- Paused videos stay paused.
- Snapshot expires after 2 minutes and is cleared after restore.
