# YouTube Float v3.36

## Overview
Fixes the v3.35 close/tab UX regressions.

## Changes
- Close is a Hermes tab-strip glyph, not an in-player button near volume.
- Player tab blocks the context-menu path that disabled the whole plugin.
- Status chip toggles open/closed based on player state.
- Module-level live player state survives pane remounts from layout movement.

## Verification
- `node --check plugin.js`
- Runtime import stub confirmed active pane has `stripTools` and `tabWrap`.
