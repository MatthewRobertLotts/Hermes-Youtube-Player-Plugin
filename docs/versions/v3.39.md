# YouTube Float v3.39

## Overview
Fixes v3.38 polish and a reload-loop regression.

## Root Cause
Persisted resume state could be reused after the placement switch that created it, making the player reload with a stale `t=` start time.

## Changes
- Resume state is module-memory only, not `ctx.storage`.
- Chip pulses as a whole.
- Closed chip colour is stronger red.
- Floating `×` is inserted next to the built-in collapse arrow.

## Verification
- `node --check plugin.js`
- Runtime import stub confirmed floating registration.
