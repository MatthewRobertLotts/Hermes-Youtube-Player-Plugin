# YouTube Float v3.124

## Overview
Adds a safety-first updater contract without changing player UI or media behavior.

## Changes
- Validates GitHub Release metadata and stable zip artifact before update fallback.
- Adds updater contract tests for version states, invalid releases, wrong plugin IDs, wrong versions, oversized downloads, invalid origins, failed writes, and fallback behavior.
- Documents updater trust model in `SECURITY.md`, README, and architecture notes.
- Keeps self-replacement disabled unless Hermes provides an explicit supported updater bridge.
