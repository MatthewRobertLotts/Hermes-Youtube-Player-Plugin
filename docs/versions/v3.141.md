# YouTube Float v3.141

## Overview
Hardens the player integration API v1 as though an external third-party plugin already depends on
it. No new endpoints, no API version bump — v1 remains backward compatible.

## Changes
- Control-timeout guard: a command that neither resolves nor rejects within 5s returns
  `code:'player_error', error:'control timed out'` instead of hanging the consumer.
- Envelope hardening: `params` must be an object (arrays/strings/null -> invalid_argument).
- `canonicalUrl` now emits `/shorts/` for shorts; `isShort` derived from the active queue item.
- Field-ladder correction: `isShort`/`isLive` are best-effort, not guaranteed; docs updated.
- Aligned finite-number coercion between `src/` and the bridge (blank/whitespace rejected).
