# YouTube Float v3.43

## Overview
Makes docked max-stretch video visibly larger using CSS sizing instead of JS width observation.

## Changes
- Removed `ResizeObserver` dependency.
- Docked player height uses `min(78vh, calc((100vw - 420px) * 0.5625))`.
- Docked webview width uses `min(100%, calc(78vh * 1.7778), calc(100vw - 420px))`.

## Verification
- `node --check plugin.js`
- Static checks confirmed v3.43 marker, CSS scale expressions, no ResizeObserver, no default query/API-key pattern.
