# YouTube Float v3.22

## Overview
Fixes account feed auto-loading and replaces fragile Your Playlists channel resolution with direct signed-in You page scraping.

## Changes
- Valid cache-busting URLs for account feed auto-loads.
- Your Playlists loads `https://www.youtube.com/feed/you` in the covered visible pane and scrapes playlist tiles.
- Search draft remains blank by default.

## Verification
- `node --check plugin.js`
- Source contains no built-in `king boomer` query and no hardcoded YouTube API-key pattern.
