# YouTube Float v3.32

## Overview
Moves placement switching out of the lower controls and into a pin icon beside the timeline.

## Behavior
- Pinned icon means docked.
- Unpinned/location icon means floating.
- Button sits left of the progress bar; volume stays right.
- Size remains its own control.
