# YouTube Float v3.46

## Overview
Uses controlled cover-fill in docked mode to remove unnatural side/moat bars.

## Changes
- Adds `fitScript(mode)` injected into the YouTube watch page.
- Docked pane uses `object-fit: cover` for the internal video.
- Floating/non-docked mode stays `object-fit: contain`.
- Webview returns to full player width; overflow is hidden inside YouTube player containers.

## Verification
- `node --check plugin.js`
- Static checks confirmed v3.46 marker, fit script, docked cover path, and account cache path.
