# YouTube Float v3.40

## Overview
Fixes v3.39 reload loop and header/status polish.

## Root Cause
`resumeStart` was derived during render from live progress state. Progress updates could change the webview `src`, causing reload loops.

## Changes
- `resumeStart` is frozen in a ref on mount.
- Resume handoff remains volatile memory only.
- Chip colour uses inline green/red.
- Floating collapse and close controls are grouped together.

## Verification
- `node --check plugin.js`
- Checks confirmed no persisted resume and frozen `resumeStartRef`.
