# YouTube Float v3.126

## Overview
Hardens deterministic playback and queue behavior without redesigning the UI.

## Changes
- Clamps seek/rewind/forward commands.
- Fixes Shorts auto-advance to avoid repeating the same Short when another Short exists.
- Adds tests for playback command math, quality/caption fallback, queue boundaries, duplicates, and empty queues.
- Adds `docs/release-tests/v3.126-playback-reliability.md` for live webview cases.
