# YouTube Float v3.115

## Overview
Adds a safe in-plugin update check using GitHub Releases.

## Changes
- Adds `Check updates` button.
- Queries the repository latest release endpoint.
- Compares installed vs available version.
- Opens release notes when a newer version exists.
- Does not download or replace plugin files automatically.

## Verification
- `node --check plugin.js`
- `node --test tests/*.test.mjs`
- `node scripts/check-release.mjs`
- GitHub Actions workflow
