# YouTube Float v3.48

## Overview
Safe rollback from the broken docked cover-fill attempt.

## Research Result
- MDN: `object-fit: contain` letterboxes/pillarboxes; `cover` crops.
- MDN: `object-fit` has no effect on iframes, embeds, or fenced frames.
- YouTube IFrame/player API exposes explicit width/height sizing (`setSize`).

## Changes
- Removed `fitScript` and the `object-fit: cover` injection.
- Restored stable centered docked scaling.
- Kept account label persistence.

## Next Attempt
