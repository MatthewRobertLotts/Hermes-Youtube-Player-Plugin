# YouTube Float v3.111

## Overview
Adds opt-in diagnostics for tracing plugin failures without dumping private YouTube session data.

## Changes
- Adds central diagnostic logger.
- Adds Debug toggle and Copy diagnostics action.
- Logs account probe, History loading, playlist loading, player command, caption, and Media Session failures.
- Keeps logging off by default.

## Verification
- `node --check plugin.js`
- `node --test tests/*.test.mjs`
- `node scripts/check-release.mjs`
- GitHub Actions workflow
