# YouTube Float v3.37

## Overview
Adds a close button to the floating player's own top bar.

## Changes
- Injects a small `×` into Hermes' floating-pane header for `player-floating`.
- Button uses `data-floating-no-drag` so it does not start dragging.
- Routes through `closePlayerPane()` like the docked tab close glyph.
