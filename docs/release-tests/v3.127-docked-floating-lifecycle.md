# v3.127 Docked/Floating Lifecycle Manual Checklist

Live Hermes/Electron checks. Do these with a signed-in YouTube session and real playback.

## Transitions
- [ ] Docked -> Floating during playback: video keeps playing, no duplicate audio, no second webview.
- [ ] Floating -> Docked during playback: playback and queue keep their place.
- [ ] Rapid Dock/Float spam (button 20x): ends stabilised, exactly one player pane, no orphaned hidden webview.
- [ ] Close during a transition: no crash; reopen shows one clean player.

## State survival across dock/float + close/reopen
- [ ] Current video.
- [ ] Exact playback position (within a couple of seconds).
- [ ] Play/pause state.
- [ ] Volume.
- [ ] Queue list and the **current queue index** (Next/Prev still line up after the swap).
- [ ] Loop mode.
- [ ] Selected caption + quality preference.
- [ ] Floating geometry restored (width/height/anchor) on reopen.

## No duplicates
- [ ] No duplicate audio during swap.
- [ ] Only one active player decoder for the same video (task manager / diagnostics shows one).
- [ ] No orphaned hidden webviews after repeated cycles.
- [ ] One progress timer; no Media Session double-handlers (OS media keys act once).

## Resize / reload
- [ ] Minimum player dimensions still usable (mini / small).
- [ ] After unexpected webview reload, player resumes current video (does not spin or double-play).

## Restart / route
- [ ] Hermes restart/reload: player re-registers in persisted docked/floating placement; last state restores.
- [ ] Plugin route navigation (`/youtube`) during playback does not kill audio or spawn a second player.
