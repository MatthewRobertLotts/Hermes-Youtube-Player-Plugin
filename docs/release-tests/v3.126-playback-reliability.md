# v3.126 Playback Reliability Manual Checklist

Use this for live Hermes/Electron/YouTube behavior that offline CI cannot honestly cover.

## Playback

- Normal video: Play, pause, spam Play/Pause 10 times, seek to start, seek to middle, seek near end.
- Transport: `-10s` at 3 seconds stays at start; `+10s` near the end clamps to end.
- Buffering: seek while the spinner/buffering state is visible; controls recover.
- Ended state: video end pauses or advances according to queue/loop state.
- Long video: multi-hour timestamp/timeline still displays and seeks.
- Livestream/premiere: opens without breaking controls; duration may be unavailable.
- Unavailable/private/deleted video: player fails gracefully and other shelves still work.

## Queue

- Next/Prev on first item, middle item, last item.
- Empty queue controls do nothing visible/bad.
- Playlist item opens playlist and advances to the next playlist item.
- Switching from search queue to playlist queue while playing does not keep stale queue indexes.
- Shorts sequence advances to another Short and does not repeat the same Short when another Short exists.
- Duplicate-looking rows do not create confusing repeated queue entries.

## Loop

- Loop Off: end of queue pauses.
- Loop One: current video restarts once/uses YouTube ended handling without skipping queue.
- Loop ∞: YouTube loops current media where supported.

## Quality and captions

- Auto quality works.
- Manual quality changes when available.
- Unavailable quality falls back without breaking playback.
- Captions Off disables captions.
- Captions On/switch track works when tracks exist.
- No captions/unavailable prior track falls back to Off.

## Failure/session

- Temporary network interruption: existing version stays open; controls recover after network returns.
- Sign out while player is open: playback remains safe; signed-in shelves degrade.
- Switch YouTube account while open: History/subscriptions follow the current account after reload.
- Close/reopen, dock/float, then verify playback state resumes without duplicate panes.
